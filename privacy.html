Privacy notice

This sample site uses optional, consent-based analytics.

What is collected

Only after you select “Allow analytics”, the site sends your public IP address (which the hosting network supplies), approximate city/region/country based on IP if available, browser, operating system, device category, screen dimensions, timezone, page path, and server visit time.

What is not collected

This site does not request precise GPS location, contacts, phone number, email, passwords, camera, or microphone.

Your choice

Select “Decline” to use the site without sending analytics. You can clear this site's local storage to see the choice prompt again. The site owner should publish their contact details, retention period, and applicable legal basis before using this on a real public website. Delete records when no longer needed and restrict dashboard access.
